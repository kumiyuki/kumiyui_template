# kumiyui_template
the template for the [kumiyui](https://github.com/kumiyuki/kumiyui) framework.

## userscript header
look at the [./package.json](./package.json) to edit userscript header

## build
```sh
mkdir ./dest
bun kumiyui build
```

## build (with minification)
```sh
mkdir ./dest
bun kumiyui build --minify
```
